# Programmable Networks lab portfolio

My WIC2005 network labs and generated pages use the student ID suffix `4940`.
The published pages are [Week 2](https://darrellleexd.github.io/programmble_network/),
[Week 3](https://darrellleexd.github.io/programmble_network/week3/),
[Week 4](https://darrellleexd.github.io/programmble_network/week4/), and
[Week 6](https://darrellleexd.github.io/programmble_network/week6/).

Week 6's hands-on lab and its evidence are in `netlab/week6-lab/`. The
data-centre overlay assignment uses `netlab/build_overlay.py`, the four YAML
designs and `netlab/evidence6/`; `netlab/make_page6.py` publishes its report
to `docs/week6/`.

## AI use

I used OpenAI Codex (GPT-6) to help interpret the Week 6 instructions, draft
the Python VXLAN command generator and MTU check, prepare the repeatable Linux
lab run and evidence checks, and edit the page and explanations. I checked the
design against the course requirements and ran the code and packet tests in
the course Mininet image on a GitHub Actions Linux runner. The evidence files
are captured command output from those runs.
